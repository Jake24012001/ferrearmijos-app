# ferrearmijos-app
Proyecto de Programacion Movil
FerreArmijos es una aplicación orientada a la gestión y comercialización de productos ferreteros y materiales de construcción. Su objetivo es facilitar a los usuarios la consulta de productos, la gestión de compras y el acceso a la información de manera rápida y sencilla, mediante una interfaz intuitiva. El proyecto busca optimizar los procesos de venta y mejorar la experiencia de los clientes a través de herramientas tecnológicas.
